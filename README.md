# Workflow Assignment

This project is part of the Workflow course assignment. The goal of the project is to improve the development workflow, code quality, and test coverage of an existing Vanilla JavaScript website.

The project has been configured with ESLint, Prettier, pre-commit hooks, unit testing with Vitest, and end-to-end testing with Playwright.

## Built With

- Vanilla JavaScript
- HTML
- CSS
- ESLint
- Prettier
- Husky
- lint-staged
- Vitest
- Playwright
